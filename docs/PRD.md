# PRD: 다이버즈 협업툴 (DIVERZ Work)

**작성일:** 2026-05-20
**버전:** v0.2
**기반 자료:** marketing-pm-prototype.html, Google Sheets (매출/매입/상품/광고주 데이터)

---

## 1. 제품 개요

### 1.1 배경
다이버즈는 IMC 마케팅 대행사로 B2B(리워드 솔루션 판매)와 B2C(네이버 플레이스·쇼핑 상위노출, 블로그 체험단, 예약자 리뷰 등)를 병행 운영한다. 현재 업무가 구글 시트 등 분산 도구로 처리되어 프로젝트 누락, 매출 추적 어려움, 내부 소통 비효율 문제가 발생하고 있다.

### 1.2 목적
프로젝트 전 생애주기(견적 → 수주 → 집행 → 정산)를 단일 플랫폼에서 관리하고, 알람과 내부 채팅을 통합하여 업무 누락을 방지한다.

### 1.3 범위
- **대상 사용자:** 다이버즈 내부 직원 전체
- **플랫폼:** 웹 앱 (PC 브라우저 우선, 태블릿 대응)
- **외부 연동:** 전자세금계산서 API, 네이버 관련 API

### 4.1 대시보드 (Home)

**목적:** 오늘의 업무 현황을 한눈에 파악

#### 주요 지표 카드
| 지표 | 설명 |
|------|------|
| 이번 달 매출 | 월 누계 총 판매가 합계 |
| 이번 달 마진 | 월 누계 (판매가 - 원가) |
| 평균 마진율 | 월 누계 마진율 |
| 진행 중 캠페인 수 | 현재 진행중 상태 프로젝트 수 |

#### 종료 임박 프로젝트 패널
- 탭 필터: 전체 / 오늘 / D-1 이내 / D-3 이내 / D-7 이내
- 표시 항목: 프로젝트명, 광고주, 종료일, D-Day 배지, 매출, 마진, 담당자
- 프로젝트명 클릭 → 해당 프로젝트 상세로 이동

#### 미처리 알람 요약
- 확인하지 않은 알람 수 배지 + 빠른 목록 표시

### 4.4 견적서 관리

**목적:** 표준 견적서 양식 제공 및 수주 전환까지 추적

#### 견적서 목록
- 표시 항목: 견적번호, 광고주, 견적일, 유효기간, 총 금액, 상태, 담당자
- 상태 필터: 작성중 / 발송 / 검토중 / 수주 / 취소
- 견적 복사 기능

#### 견적서 생성
1. 광고주 선택 (기존 광고주 검색 또는 신규 등록)
2. 서비스 항목 추가
   - 상품 카탈로그에서 선택 → 수량·단가·기간 입력
   - 항목 추가/삭제 자유
3. 할인 및 부가세 설정
4. 합계 자동 계산 (공급가액 / 부가세 / 합계)
5. 견적 유효기간 설정

#### 견적서 상태 흐름
```
작성중 → 발송 → 검토중 → 수주 (→ 프로젝트 자동 생성)
                        → 취소
```

#### 견적서 PDF 출력
- 다이버즈 로고·직인 포함 표준 양식
- 공급자 정보, 공급받는자 정보, 품목 테이블, 합계 포함

#### 수주 전환
- 수주 확정 시 버튼 클릭 → 프로젝트 자동 생성
- 견적 항목이 집행 상품으로 자동 매핑

### 4.5 프로젝트 관리

**목적:** 수주 캠페인의 일정·집행·정산 전 과정 추적

#### 프로젝트 목록
- 뷰: 테이블 목록 / 칸반 보드 (상태별) / 캘린더 (마감일 기준)
- 필터: 상태, 담당자, 광고주, 기간
- 검색: 프로젝트명 또는 광고주명
- Excel 내보내기

#### 프로젝트 등록/수정

**기본 정보**
| 필드 | 필수 | 설명 |
|------|------|------|
| 프로젝트명 | 필수 | |
| 광고주 | 필수 | 광고주 관리에서 선택 |
| 담당자 | 필수 | 내부 직원 선택 |
| 시작일 / 종료일 | 필수 | |
| 총 판매가 | 필수 | 광고주에게 청구할 금액 |
| 상태 | 필수 | 대기 / 진행중 / 완료 / 보류 / 취소 |
| 메모 | 선택 | |

**집행 상품** (반복 추가 가능)
| 필드 | 필수 | 설명 |
|------|------|------|
| 상품 선택 | 필수 | 상품 카탈로그에서 선택 |
| 건당 단가 | 자동 | 상품 선택 시 원가 자동 입력 |
| 일일 수량 | 필수 | 건/일 |
| 시작일 / 종료일 | 필수 | 상품별 집행 기간 |
| 집행 기간(일) | 자동 | 시작일~종료일 계산 |
| 총 원가 | 자동 | 단가 × 수량 × 기간 |

**재무 요약** (자동 계산)
- 총 원가 합계 / 총 판매가 / 마진 / 마진율

**거래처 계정 정보** ← 신규 추가
| 필드 | 필수 | 설명 |
|------|------|------|
| 플랫폼명 | 필수 | 네이버, 인스타그램, 유튜브 등 |
| 계정 ID / URL | 필수 | 관리 대상 계정 |
| 로그인 ID | 선택 | 계정 관리용 |
| 로그인 PW | 선택 | 암호화 저장, 권한자만 열람 |
| 비고 | 선택 | 계정 관련 특이사항 |
- 계정 정보는 복수 추가 가능 (한 프로젝트에 여러 플랫폼 계정)
- 비밀번호는 마스킹 처리, Admin/Manager만 열람 가능

#### 프로젝트 상세 페이지 구성
1. **기본 정보** — 프로젝트명, 광고주, 담당자, 기간, 상태
2. **재무 정보** — 판매가 / 원가 / 마진 / 마진율 카드
3. **집행 상품** — 상품별 일일수량·기간·원가 테이블
4. **거래처 계정 정보** — 플랫폼별 계정 목록 (PW 마스킹)
5. **커뮤니케이션 로그** — 타임라인 형식 메모 + 파일 첨부
6. **정산 현황** — 매출/매입 정산 상태 요약

#### 프로젝트 상태
- **대기:** 수주 확정 후 집행 전
- **진행중:** 집행 중
- **완료:** 집행 및 정산 완료
- **보류:** 일시 중단
- **취소:** 취소 처리

```
광고주 (Client)
├── 프로젝트 (Project) 1:N
│   ├── 집행상품 (ProjectProduct) 1:N → 상품(Product) 참조
│   ├── 거래처계정 (AccountInfo) 1:N  ← 신규
│   ├── 커뮤니케이션로그 (Log) 1:N
│   └── 채팅채널 (Channel) 1:1 (자동생성)
└── 견적서 (Quote)
    └── 견적항목 (QuoteItem) 1:N → 상품(Product) 참조

사용자 (User)
├── 담당 프로젝트 (Project) 참조
├── 알람 (Notification) 1:N
└── 채팅메시지 (Message) 1:N

상품 (Product) — 마스터
└── 카테고리, 건당단가, 판매단가
```

## 11. 프로토타입 기반 UX 원칙

HTML 프로토타입에서 검증된 다음 패턴을 그대로 유지한다:
- 상단 컬럼명 클릭으로 테이블 정렬 (⇅ 아이콘)
- 테이블 행 클릭으로 상세 페이지 이동
- 상태 배지: 초록(완료/활성) / 노랑(진행중/대기) / 빨강(D-Day/미처리)
- 집행 상품 원가 = 건당단가 × 일일수량 × 집행기간(일) 자동 계산
- Excel 내보내기 버튼 (주요 테이블 전체)
- 등록은 모달, 상세·수정은 전체 페이지 전환
